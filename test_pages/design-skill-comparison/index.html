디자인 방향 neutral 모노크롬 테마, Figtree, 모션 거의 없음. 조용하고 일관된 앱 UI 느낌 스킬이 딜한 팔레트(다크 green-black-bone / 라이트 white-link-blue), IBM Plex Sans·Mono, collage 히어로(라이브 테일 창 + Slack 알림), 한 섹션 = 한 화면, WebGL 그레인 효과와 등장 모션 Dark Mode (OLED) + run green 강조, Inter + JetBrains Mono, 인터랙티브 제품 데모
산출물 크기 약 1.7MB (JS gzip 약 471KB) 약 928KB (kit asset 41개 포함, 전송 약 327KiB) 약 84KB (gzip 약 22KB)
장점 컴포넌트·토큰·테마가 하나의 체계라 일관성이 높음. 접근성·반응형(모바일 드로어 등)이 컴포넌트에 내장. 문서를 CLI 로 바로 조회 한 섹션 = 한 화면, 같은 가장자리, 실제 로고, 제품 UI 목업, 모션, 라이트/다크, 성능(CLS 0)까지 체커가 실측으로 잡아줘 기본 품질과 일관성이 높음 대비·포커스·reduced-motion·차트 접근성 등 체크리스트가 구체적. 스택 제약이 없어 결과가 가벼움
단점 마케팅 랜딩용 블록(가격표·기능 그리드·CTA) 없음. 번들이 큼. 한국어 줄바꿈 등은 테마 확장까지 거쳐야 함 규칙·문서가 방대하고 체커 1회가 수 분이라 시간·토큰 비용이 큼. 영어·라틴 전제 체커(한글 제목 길이 오판정 등)와 kit 간 충돌 때문에 우회 CSS 가 생김 검색 키워드에 따라 결과가 크게 흔들림. 생성된 MASTER 에 대비 미달·라이트/다크 혼재 등 모순이 있어 직접 교정 필요. 문서가 React Native 전용으로 쓰여 있음
검증 방식 astryx doctor 정적 규칙 검사 (권장, 강제 아님) headless Chrome 체커(카피·일관성·레이아웃·성능) + Stop hook 으로 finish gate 강제 (PASS 전 종료 불가, 최대 3라운드) 검사 스크립트 없음, 문서 체크리스트만
