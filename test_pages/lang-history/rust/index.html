Rust

2015 년 1.0 부터 6 주 주기, 3 년마다 edition. 패키지 관리는 처음부터 cargo 하나였던 반례이고, 그 밖의 영역은 "서드파티가 먼저 검증 → 더 빠른 하나로 수렴 → 공식 컴포넌트나 std 로 흡수" 를 반복합니다. 단 async 런타임과 에러 crate 는 의도적으로 std 밖에 남겨 둡니다.
