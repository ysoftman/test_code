Go modules 1.11 (2018-08) 실험 → 1.14 정식 → 1.16 기본

What

  • 1.13 proxy.golang.org / sum.golang.org 로 배포 인프라까지 갖추자 서드파티가 설 자리가 없어짐

godep · glide · govendor · gb · gom · dep 2013 – 2020

What
GOPATH 위에 얹은 서드파티 의존성 고정 도구들. 각자 다른 lock 파일 형식 (Godeps.json / glide.lock / Gopkg.lock).

  • dep (2017): Go 팀 후원 "공식 실험". 그러나 SAT 기반 해석이 복잡·느리다는 판단으로 vgo 에 밀려 2020 년 아카이브
