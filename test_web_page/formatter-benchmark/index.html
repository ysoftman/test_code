포맷터 벤치마크

결과를 불러오는 중

    포맷 시간

    짧을수록 빠르다. 막대 길이는 코퍼스마다 가장 느린 도구 기준이고, ×N 은 가장 빠른 도구 대비 배수. 막대에 마우스를 올리면 편차와 최소, 최대가 나온다.

    Prettier 와 같은 출력

    프로젝트 원본 1벌을 각 도구로 포맷한 뒤 Prettier 결과와 파일 단위로 바이트 비교.

    측정 방법

    • hyperfine 쓰기 모드(--write), 워밍업 1회. 실행마다 코퍼스를 원복하고 원복 시간은 측정에서 뺀다.
    • 코퍼스: test_web_page 의 git 추적 소스.
    • 환경: 불러오는 중
    • Biome 은 HTML 포맷터를 켜고 Prettier 에 맞춘 설정으로 실행했다: indentStyle: space, indentScriptAndStyle(.vue 는 끔), selfCloseVoidElements: always.
    • 재현: 이 디렉토리에서 bun run bench 를 실행하면 results.json 이 갱신된다.

    해석할 때

    • Prettier 는 Node 에서 단일 스레드로 돌고, Biome 과 bun 은 네이티브 바이너리로 모든 코어를 쓴다. 차이의 상당 부분이 여기서 나온다.
    • 1벌 코퍼스는 파일이 적어 시작 시간이 대부분이다. 처리량 차이는 큰 코퍼스에서 봐야 한다.
    • ×N 코퍼스는 같은 파일을 복제한 것이라 실제 대형 저장소와 파일 분포가 다를 수 있다.
    • bun fmt 은 PR #44805 로 main 에 들어왔고 아직 태그 릴리스가 없다. main 최신 빌드인 canary 를 썼다.
    • Biome 의 HTML 포맷터는 아직 실험적이다. html.formatter.enabled 기본값이 false 이고, Vue, Svelte, Astro 마크업은 html.experimentalFullSupportEnabled 도 켜야 한다 (language support).
